# 🍽️ FreshBite - Online Food Ordering Website

## 📌 Project Description

FreshBite is a user-friendly online food ordering website that allows users to explore restaurants, browse food items, add food to their cart, and place orders online.

## ✨ Features

- 🏠 Home page with food categories, featured dishes, and special offers
- 🍴 Restaurant listing with cuisine, rating, and price filters
- 🍕 Food menu with images, descriptions, prices, and dietary tags
- 📋 Product details with ingredients and nutritional information
- 🛒 Shopping cart with quantity adjustment and total calculation
- 💳 Checkout page with delivery address, payment method, and delivery time
- 👤 User account with profile, order history, saved addresses, and wishlist
- 🔐 Login and registration
- ℹ️ About Us page
- 📞 Contact Us page
- 📱 Responsive design for mobile and desktop

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 📂 Project Structure

- `index.html` - Home page
- `restaurants.html` - Restaurant listing
- `menu.html` - Food menu
- `product.html` - Product details
- `cart.html` - Shopping cart
- `checkout.html` - Checkout page
- `account.html` - User account
- `login.html` - Login/Register
- `about.html` - About Us
- `contact.html` - Contact Us
- `style.css` - Website styling
- `script.js` - Website functionality

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Explore the FreshBite website.

## 🎯 Project Goal

The goal of FreshBite is to provide a simple and convenient platform for users to discover restaurants and order food online.
